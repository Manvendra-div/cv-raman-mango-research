# Dashboard Outputs

The research dashboard is implemented as a local Streamlit app.

## Main Files

| File | Description |
|---|---|
| `src/research_dashboard/dashboard.py` | Dashboard implementation |
| `research_dashboard/run_dashboard.ps1` | PowerShell launch script |
| `research_dashboard/README.md` | Dashboard usage notes |
| `research_dashboard/dashboard_scope.md` | Data sources and dashboard coverage |
| `outputs/dashboard/research_dashboard_summary.json` | Machine-readable dashboard summary |
