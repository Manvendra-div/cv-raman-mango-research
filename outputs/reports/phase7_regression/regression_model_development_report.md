# Phase 7.1 Mango Yield Regression Report

Generated by `src/modeling/phase7_1_train_regression.py`.

## Target

- `Mango_Yield` in kg/tree.

## Feature Set

- Selected numeric features: 34
- Categorical features encoded: Village, Mango_Variety, Soil_Depth, Sampling_Season, Management
- Preprocessing is fit on the train split only inside each model pipeline.

## Models Trained

- `Mean_Baseline`: Mean-value dummy baseline.
- `Linear_Regression`: Ordinary least-squares linear regression baseline.
- `Elastic_Net`: Regularized linear model with L1/L2 penalty.
- `Linear_SVR`: Scalable linear support vector regression.
- `Random_Forest`: Random Forest regressor for nonlinear tabular interactions.
- `Gradient_Boosting`: Gradient Boosting regressor for nonlinear threshold effects.
- `MLP_Regressor`: Neural network baseline for structured tabular data.
- `XGBoost`: Optional XGBoost regressor, included when xgboost is installed.
- `LightGBM`: Optional LightGBM regressor, included when lightgbm is installed.
- `Hybrid_Rule_Guided_GB`: Gradient Boosting plus transparent agronomic rule adjustment.
