- `Nutrient_Availability` classes: Optimal, High

## Feature Set

- Selected numeric features: 34
- Categorical features encoded: Village, Mango_Variety, Soil_Depth, Sampling_Season, Management
- Preprocessing is fit on the train split only inside each model pipeline.

## Models Trained

- `Majority_Baseline`: Most-frequent-class control baseline.
- `Logistic_Regression`: Balanced Logistic Regression baseline.
- `Linear_SVM`: Calibrated linear Support Vector Machine classifier.
- `Random_Forest`: Random Forest classifier for nonlinear tabular interactions.
- `Gradient_Boosting`: Gradient Boosting classifier for nonlinear threshold effects.
- `MLP_Classifier`: Neural network classifier for structured tabular data.
- `Hybrid_Rule_Guided_GB`: Gradient Boosting plus transparent agronomic rule adjustment.
