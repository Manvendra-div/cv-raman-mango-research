# Validation Data Inputs

This folder stores Phase 10 real-world validation inputs.

## Files

| File | Description |
|---|---|
| `real_sample_validation_template.csv` | Empty template generated by Phase 10 for measured orchard samples |
| `real_sample_validation_input.csv` | Editable input file for real orchard samples |
| `field_intervention_validation_template.csv` | Empty template generated by Phase 10 for intervention monitoring |
| `field_intervention_validation_input.csv` | Editable input file for treatment/control field observations |

Run Phase 10 again after adding rows:

```powershell
python src\validation\phase10_validation.py
```

Keep column names unchanged so the validation script can reuse the trained pipelines and compute observed-vs-predicted comparisons.
