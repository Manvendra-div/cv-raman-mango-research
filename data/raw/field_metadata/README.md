# Raw Field Metadata

Store completed Phase 2 and Phase 3 field metadata files here.

Use the templates from:

- `phase_2_study_design_sampling_framework/templates/orchard_registry_template.csv`
- `phase_2_study_design_sampling_framework/templates/field_metadata_template.csv`
- `phase_2_study_design_sampling_framework/templates/field_visit_schedule.csv`

Recommended naming:

```text
orchard_registry_YYYY-MM-DD.csv
field_metadata_VISITID_YYYY-MM-DD.csv
field_notes_VISITID_YYYY-MM-DD.md
```

Do not store farmer names or personal contact details in analysis metadata files. Use coded consent IDs.
