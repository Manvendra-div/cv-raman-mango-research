# Raw Initial Real-Sample Dataset

Store completed Phase 3 initial real-sample datasets here.

Template:

- `phase_3_soil_microbiome_data_collection/templates/initial_real_sample_dataset_template.csv`

Recommended naming:

```text
initial_real_sample_dataset_VISITID_YYYY-MM-DD.csv
initial_real_sample_dataset_annual_YYYY.csv
```

Use one row per parent composite sample. Lab-derived columns should remain blank until Phase 4.
