## Phase 2 Design Decision

The older real-sample proposal of 3 orchards and 12 composite datasets per year is preserved as background only. It is not sufficient for model refinement. Phase 2 therefore defines:

- A minimum pilot-validation design: 12 orchards, 3 seasonal windows, 2 soil depths, 72 core composites per year, plus QC samples.
- A recommended model-refinement design: 36 orchards, 3 seasonal windows, 2 soil depths, 216 core composites per year, plus QC samples.
- An optional quarterly design: 36 orchards, 4 field windows, 2 soil depths, 288 core composites per year, plus QC samples.
